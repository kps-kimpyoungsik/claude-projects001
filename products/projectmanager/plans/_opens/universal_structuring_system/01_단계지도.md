## 3. 실제 순서 — 의존이 강제하는 것만

```
                     [이미 동작 중]
     P1 어휘(112건) · P2 표준5종+바인딩+학습 · CoreView 뷰3개
                            │
          ┌─────────────────┼──────────────────┐
          ▼                 ▼                  ▼
    U2 기준→표준       G1 case_usage      U5 측정 루프
    (P7 승인 호출)     (기록만, 1인일)     (gold+precision)
          │                 │                  │
          ▼                 │                  │
    U1 추출기 4종           │                  │
          │                 │                  │
          ▼                 ▼                  ▼
    U3 정제 ────────────────┴──────────────────┘
          │
          ├──▶ U4 검토·승인 화면 ──▶ U6 질의 ──▶ U7 투영(산출물)
          │
          └──▶ [데이터셋 30개 이상일 때] G3(=P5) ──▶ G4 추천
```

**강제 의존은 넷뿐이다:**
1. `U2 → U1` — 무엇을 채울지(표준) 알아야 추출 결과를 쓸 데가 있다. *반대는 아니다* — 표준은 기준 문서에서 나오지 자료에서 나오지 않는다.
2. `U3 → U4 → U6 → U7` — 값이 있어야 검토하고, 검토해야 질의하고, 승인해야 출력한다.
3. `U2 → P7` — 표준 등재는 SAG 승인을 거친다(호출이지 선행 구현이 아니다. SAG는 **이미 설계 완료**).
4. `G1은 의존 없음` — 지금 당장 가능. 그리고 **미루면 과거를 복원할 수 없다.**

**나머지는 전부 병렬 가능하거나 보류 대상이다.**

## 4. 보류 판정 — 지금 만들면 검증할 대상이 없는 것

DDS가 **3사이클 연속 같은 벽**을 겪었다(04 §10.4: "기능을 쌓았지만 실데이터에서 한 번도
작동하지 못했다"). 같은 함정을 다시 밟지 않기 위한 보류 기준:

| 항목 | 보류 사유 | 착수 조건 (수치) |
|---|---|---|
| **G3(=P5)·G4** | 데이터셋 **9개**(실측 6+뷰3). 9개는 사람 눈으로 다 본다 | **데이터셋 30개 이상** |
| **P4 CQG** 자격게이트 | 거를 가비지가 없다 — 9개 전부 의미 있는 표 | 데이터셋 30개 이상 ∧ 미분류 5개 이상 |
| **P6 동적 발행** | 발행할 뷰 수요가 아직 없다 | 저장된 질의 요구 3건 이상 |
| **U8** ExampleAdapter | U2(템플릿·포맷)로 먼저 검증 | U2 실템플릿 1건 성공 후 |
| **U9** pdf·가이드 | 실제 pdf 자료 유입 전 | pdf 기초자료 1건 유입 |
| **U10** 임베딩 | 00 뼈대 §6 승격 조건 | L0+L1 커버리지 <85% 가 3도메인에서 측정 |
| **P3** 6축 facet | 분야·영역 분류 수요가 9개 규모에선 약함 | 데이터셋 30개 이상 |

## 7. 정정 2026-09-23 — `U2 → U1`은 강제 의존이 아니다

§3에서 `U2 → U1`을 강제 의존 1번으로 두었다. 그런데 **U1의 통과 기준**(00번 §14: 네 형식에서
같은 항목과 좌표가 나오는지)은 표준 없이도 검증할 수 있다. 추출 결과를 "쓸 데"가 필요한 쪽은
U1이 아니라 **U3(정형화)** 이다. 이 의존 표기 때문에 U1까지 "기준 문서 미확보"에 5턴 동안 묶여 있었다.

```
정정 전:  U2 → U1 → U3
정정 후:  U1 ∥ U2 → U3      (U1은 즉시 착수 가능 · U3는 둘 다 필요)
```

같은 작업에서 **이미지·음성**의 위치도 확정했다(00번 §12 보강): 원본은 받고, 텍스트는 지어내지 않는다.
`kind=image|audio`, `text=NULL` 조각이 쌓이면 그것이 OCR/STT 착수 판단의 **실측 근거**가 된다
("이미지 비중 실측 후 재검토"의 측정 수단이 이제 존재한다).
