## 3. 발견한 보안 문제 — 비밀번호 평문 적재

`서버정보` 시트에 서버 계정·비밀번호(`id / pwd : …`)가 평문으로 적재돼 `/api/datasets/{id}/rows` 로 조회되고 있었다.
지침 G-3(비밀번호는 적재하지 않는다) 위반.

- `PiiRegistry.isSecret` — `pwd:`·`password=`·`비밀번호:` 표기가 있는 칸·헤더는 `[비밀정보 차단]` (적재·전환·자유 텍스트 공통 통로 `scrub`)
- 값이 바뀐 컬럼의 min/max(원문 잔존) 삭제 · 차단 헤더 이름 충돌 방지
- 운영 DB: 4행 차단 · API 조회 `pwd` 0 · 압축 후 파일 바이트 `pwd:` 표기 **3 → 0**
- **남은 조치(사용자)**: 해당 서버 계정 비밀번호는 평문으로 저장·조회 가능했으므로 **변경 권장**. 원본 업로드 파일은 봉인돼 있다.

## 4. 검증 과정의 실수와 정정

- 검증용 인스턴스를 `-Xmx384m` 로 띄워 엑셀 DOM(POI 셀 16만)이 힙을 채워 서버가 GC 로 멈췄다 → 스레드 덤프·힙 히스토그램으로
  원인 확인(PII·CQG 객체는 1~2MB) → 실제 기동 설정(`MaxRAMPercentage=15`)으로 재검증 · 주간 API 200 · 스모크 14/14.
- 정규식 이스케이프를 파이썬으로 넣다 Java 문자열에 `\s`·`\b` 가 백슬래시 하나로 들어간 것이 이번에만 3번 — 전부 컴파일·테스트 전에 발견해 교정.
