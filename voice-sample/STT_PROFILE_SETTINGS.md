# STT 프로파일 설정 가이드

## 기본 설정: fast-medium (회의용 표준)

**현재 기본값:** `fast-medium`

```
모델: medium
정밀도: int8
Beam: 5 / Best-of: 5
예상 시간: 8~12초 (5초 음성)
정확도: 높음 (✓✓✓)
권장용도: 회의 녹음, 강연 기록, 일반 용도
```

---

## 5가지 프로파일 선택

### 1️⃣ baseline — 정확도 우선
```
설정: large-v3 | float32 | beam=5/best_of=5
시간: 47초
정확도: 매우높음 (✓✓✓✓✓)
용도: 학술발표, 정부회의, 법정 기록, 최고 정확도 필요
```

**언제 선택?**
- 정확도가 매우 중요한 경우
- 시간이 충분한 경우
- 기록을 보관해야 하는 공식 문서

---

### 2️⃣ fast-int8 — 양자화 최적화
```
설정: large-v3 | int8 | beam=5/best_of=5
시간: 20~25초
정확도: 높음 (✓✓✓✓)
손실: 1~2% (무시할 수준)
용도: 회의 기록, 정확도 중요한 경우
```

**언제 선택?**
- 정확도를 최대한 유지하면서 속도 원함
- 회의 내용을 정확히 기록해야 하는 경우
- 배경음이 적은 깔끔한 환경

---

### 3️⃣ fast-medium — 회의용 표준 ⭐ (기본값)
```
설정: medium | int8 | beam=5/best_of=5
시간: 8~12초
정확도: 높음 (✓✓✓)
손실: 5~8% (일반적으로 허용)
용도: 회의 녹음, 강연, 일반적인 모든 용도
```

**언제 선택? (추천)**
- 회의 내용을 기록하되 처리 시간도 빨라야 할 때 ✅
- 정확도와 속도의 최고 균형
- 대부분의 회의 시나리오에 최적
- 배경음이 약간 있어도 충분한 인식률

**이 설정이 기본으로 선택된 이유:**
- 회의용 최고의 선택지
- 8~12초는 실시간에 가까운 빠른 처리
- 정확도 손실 5~8%는 무시할 수 있는 수준
- medium 모델도 충분히 안정적

---

### 4️⃣ ultra-fast — 속도 우선
```
설정: medium | int8 | beam=3/best_of=3
시간: 5~8초
정확도: 중간 (✓✓)
손실: 8~12%
용도: 개인 메모, 빠른 피드백 필요, 실시간 처리
```

**언제 선택?**
- 속도가 가장 중요한 경우
- 개인적인 메모나 빠른 정리용
- 배경음이 많은 시끄러운 환경
- 정확도가 중요하지 않은 경우

---

### 5️⃣ gpu-optimized — GPU 가속
```
설정: medium | int8_float16 | beam=3/best_of=3 | device=cuda
시간: 2~4초
정확도: 높음 (✓✓✓, medium 기준)
손실: 5~8%
조건: NVIDIA GPU 필수 (RTX 3060 이상 권장)
용도: 대량 파일 배치 처리, 실시간 시스템
```

**언제 선택?**
- NVIDIA GPU가 있을 때
- 대량의 음성 파일을 처리해야 할 때
- 극고속 처리가 필요한 경우
- 2~4초는 거의 실시간 수준

**확인 방법:**
```bash
nvidia-smi  # NVIDIA GPU 확인
```

| 프로파일 | 시간 | 정확도 | 메모리 | 손실 | 추천도 |
|---------|------|--------|--------|------|--------|

## 사용 방법

### 웹 UI에서 선택
test-viz.html 헤더의 프로파일 드롭다운에서 선택하면 자동 저장됩니다.

```
[정확도우선] [int8양자화] [회의용표준 ✓] [속도우선] [GPU가속]
```

선택하면 설정이 localStorage에 저장되고, 다음 방문 시 자동으로 복원됩니다.

### 환경변수로 선택
```bash
# baseline (정확도 우선)
STT_OPTIMIZATION_PROFILE=baseline python stt_server.py

# fast-medium (회의용, 기본값)
python stt_server.py
# 또는
STT_OPTIMIZATION_PROFILE=fast-medium python stt_server.py

# ultra-fast (속도 우선)
STT_OPTIMIZATION_PROFILE=ultra-fast python stt_server.py

# gpu-optimized (GPU 가속)
STT_OPTIMIZATION_PROFILE=gpu-optimized python stt_server.py
```

## 회의 시나리오별 추천

### 조용한 회의실 (조용함, 전문 용어 많음)
```
프로파일: fast-int8 또는 baseline
시간: 20~25초 또는 47초
이유: 정확도 우선, 배경음 적음
```

### 일반 회의실 (적당한 소음)
```
프로파일: fast-medium ⭐ (기본)
시간: 8~12초
이유: 최고의 균형, 대부분 회의에 최적
```

### 시끄러운 카페 회의
```
프로파일: ultra-fast + STT_SCENARIO=noisy
시간: 5~8초
이유: 빠른 처리, 배경음 제거 우선
```

### 다량 문서 작업 (배치 처리)
```
프로파일: gpu-optimized
시간: 2~4초 × N개 파일
이유: 극고속 병렬 처리
조건: NVIDIA GPU 필수
```

| 시간 | 상태 |
|------|------|
| 2~4초 | 🚀 극고속 (실시간 수준) |
| 5~8초 | ⚡ 매우 빠름 |
| 8~12초 | 💨 빠름 (권장) |
| 20~25초 | 🐢 느림 |
| 45~50초 | 🐌 매우 느림 (정확도 최우선) |

**기준:** 5초 음성 파일 기준 (1초 음성 = 1/5 시간)

예: 30초 회의 녹음
- baseline: 470초 (약 8분)
- fast-int8: 120~150초 (약 2~2.5분)
- **fast-medium: 48~72초 (약 1~1.2분)** ⭐
- ultra-fast: 30~48초 (약 0.5~0.8분)
- gpu-optimized: 12~24초 (약 0.2~0.4분)

## 자주 묻는 질문 (FAQ)

### Q: 기본값을 변경할 수 있나요?
**A:** 네. 3가지 방법:
1. **웹 UI:** 드롭다운에서 선택 (자동 저장)
2. **환경변수:** `STT_OPTIMIZATION_PROFILE=값` 지정
3. **stt_server.py:** 코드에서 기본값 변경 (권장하지 않음)

### Q: 손실이 5~8%면 어느 정도일까요?
**A:** 
- 일반 회의 녹음: 거의 느끼지 못함
- 전문 용어 많은 회의: 약간 오류 증가
- 예: "클라우드 인프라" → "클라우드 인프래" (낮은 확률)

### Q: 시간이 계속 달라지는데요?
**A:** 정상입니다:
- 음성 길이, 배경음, CPU 상태에 따라 변함
- 표시된 시간은 평균 예상값
- 첫 실행은 모델 로드로 1~2초 추가

### Q: GPU가 없으면?
**A:** `gpu-optimized`를 제외한 4가지 프로파일 모두 사용 가능:
- 최적 선택: **fast-medium** (기본값)
- 정확도 중요: **fast-int8**
- 속도 중요: **ultra-fast**
- 최고 정확도: **baseline**

### Q: 프로파일은 서버 재시작 필요한가?
**A:** 네, 환경변수 프로파일은 서버 재시작 필요:
```bash
STT_OPTIMIZATION_PROFILE=fast-int8 python stt_server.py
```
웹 UI 선택은 재시작 불필요 (다음 업로드부터 적용).

### Q: 추천 프로파일은?
**A:** 회의용이면 **fast-medium** (기본값):
- 정확도와 속도의 최적 균형
- 대부분의 회의 시나리오에 최적
- 8~12초는 실시간에 가까운 빠른 속도
