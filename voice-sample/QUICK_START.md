## 🚀 30초 시작

### 1. 서버 실행
```bash
# 터미널 1: Python STT 서버
python stt_server.py

# 터미널 2: Go 웹 서버
go run server.go
```

### 2. 브라우저 열기
```
http://localhost:8090/test-viz.html
```

### 3. 프로파일 선택
드롭다운: **회의용표준(8~12초)** ⭐ 선택

### 4. 녹음 시작
- [▶ 시작] 클릭
- 마이크에 대고 말하기 (3~10초)
- [⏹ 중지] 클릭

### 5. 자동 요약 대기
- 녹음 중지 후 [📄 보고서 생성] 패널이 자동 표시됨
- "🔄 서버에서 자동 요약 중..." 상태 확인
- LLM 요약 → 문서 생성 완료 대기 (30초~2분)

### 6. 결과 확인
- **STT 결과:** [📝 텍스트 출력] 패널에서 확인
- **요약 보고서:** [📖 보고서 보기] 클릭 → summary.md 마크다운
- **다운로드:** [⬇ 다운로드] → Word/PDF/Excel/PowerPoint 선택

## 🎯 사용 사례별 설정

### 사례 1: 조용한 회의실 (정확도 중요)
```bash
STT_OPTIMIZATION_PROFILE=fast-int8 python stt_server.py
```
→ 프로파일: **int8양자화(20~25초)** 선택

### 사례 2: 시끄러운 카페 (빠른 처리)
```bash
STT_SCENARIO=noisy python stt_server.py
STT_OPTIMIZATION_PROFILE=ultra-fast python stt_server.py
```
→ 프로파일: **속도우선(5~8초)** 선택

### 사례 3: 일반 회의 (기본 추천)
```bash
python stt_server.py
# 기본값: fast-medium 자동 적용
```
→ 프로파일: **회의용표준(8~12초)** 선택 (이미 기본)

### 사례 4: NVIDIA GPU 있을 때
```bash
STT_OPTIMIZATION_PROFILE=gpu-optimized python stt_server.py
```
→ 프로파일: **GPU가속(2~4초)** 선택

## 📊 화면 읽는 방법

### [실시간 입력] 패널
```
파형 표시: ███░░░░ — 음성 강도 표시
VAD: 🎤 발화 중 / 무음 — 음성 활동 감지 상태
RMS: -20dB — 신호 크기 (작을수록 조용함)
경과: 00:15 — 녹음 경과 시간
```

### [저장 파이프라인] 패널
```
현재 세그먼트: 3/5 (60%) — 진행률
저장됨: 3개 — 완료된 세그먼트
처리중: 1개 — STT 처리 중인 세그먼트
완료: 0개 — 최종 완료된 세그먼트
```

### [텍스트 출력] 패널
```
[STT 완료] 표시 — 세그먼트별 처리 완료
  음성: 5.0s — 실제 음성 길이
  Whisper: 11.2s — STT 인식 시간
  화자식별: 2.5s — 화자 분류 시간
  합계: 13.8s — 전체 처리 시간

**[15:04:05] 화자1** — 타임스탬프 + 화자
본문 텍스트... — 인식된 음성 텍스트
```

## 🐛 흔한 문제

### ❌ "처리 중이라고만 나오고 끝나지 않음"
**해결:**
1. Python 콘솔에서 `[STT 완료]` 메시지 있는지 확인
2. 음성이 최소 0.3초 이상 있었는지 확인
3. 마이크 권한 확인

### ❌ "파형이 안 보임 (마이크 인식 안 됨)"
**해결:**
1. 브라우저 새로고침 (F5)
2. 주소창 마이크 아이콘 → "허용" 클릭
3. 다른 앱이 마이크 점유하지 않는지 확인

### ❌ "정확도가 떨어짐"
**해결:**
1. 프로파일을 **int8양자화** 또는 **정확도우선**으로 변경
2. 또는: `STT_SCENARIO=noisy python stt_server.py`
3. 마이크를 배경음에서 더 멀리 배치

### ❌ "GPU 프로파일 선택했는데 오류"
**해결:**
GPU가 없으면 CPU 프로파일 선택:
```bash
STT_OPTIMIZATION_PROFILE=fast-medium python stt_server.py
```
