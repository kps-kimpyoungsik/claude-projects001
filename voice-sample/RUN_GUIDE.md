# 실행 가이드 — 회의 녹음 설정

## ✅ 빠른 시작 (권장)

### 1단계: Python STT 서버 실행
```bash
# 터미널 1
python stt_server.py
```

콘솔 출력 확인:
```
======================================================================
  최적화 프로파일: FAST-MEDIUM
  설명: 회의용 표준 (80% 단축, 추천)
  예상 속도: 8~12s (5초 음성 기준)
  정확도 손실: 5~8%

  모델: medium  |  Compute: int8  |  Device: cpu
  시나리오: quiet  |  Beam: 5  |  Best-of: 5
  🎤 화자 식별 활성 (비동기 병렬 처리)
======================================================================
```

### 2단계: Go 서버 실행
```bash
# 터미널 2
go run server.go
```

### 3단계: 브라우저 접속
```
http://localhost:8090/test-viz.html
```

## 🎙️ 웹 UI 사용법

### 헤더 구성

```
┌─ 주제 입력 ── 시작/중지 ── 프로파일선택 ── 옵션(파형/글로우/흐름) ─┐
│ "회의록"      [▶시작]     [회의용표준▼]   [파형] [글로우] [흐름]   │
└────────────────────────────────────────────────────────────────────┘
```

### 1️⃣ 프로파일 선택 (필수)
```
드롭다운 [회의용표준(8~12초)] 선택
└─ 회의용 표준
   정확도: 높음 | 시간: 8~12초
   (자동 저장됨, 다음 방문 시 복원)
```

**5가지 프로파일:**
- **정확도우선(47초)** — 학술/정부용, 최고 정확도
- **int8양자화(20~25초)** — 회의 정확도 중요
- **회의용표준(8~12초)** ⭐ — 권장 선택
- **속도우선(5~8초)** — 빠른 메모용
- **GPU가속(2~4초)** — NVIDIA GPU 필수

### 2️⃣ 주제 입력
```
입력: "2024년_1월_프로젝트_미팅"
```

### 3️⃣ 녹음 시작
```
[▶ 시작] 버튼 클릭
└─ 마이크 활성화 → REC 배지 점멸
```

### 4️⃣ 실시간 모니터링

**패널 1: 실시간 입력**
```
🎤 실시간 입력
├─ 파형 표시 (음성 진폭)
├─ VAD 인디케이터 (🎤 발화 중 / 무음)
├─ RMS 레벨 표시
└─ 녹음 경과 시간
```

**패널 2: 저장 파이프라인**
```
💾 저장 파이프라인
├─ 현재 세그먼트 진행률
├─ 저장된 파일 목록
└─ 저장/처리중/완료 개수
```

**패널 3: 텍스트 출력**
```
📝 텍스트 출력
├─ STT 진행 상태 (변환 중 XX%)
├─ 타이밍 로그 (Whisper: XXs, 합계: XXs)
└─ 세그먼트별 텍스트 (화자별 색상)
```

### 5️⃣ 녹음 중지
```
[⏹ 중지] 버튼 클릭
└─ 최종 파일 저장
└─ 자동 요약 시작 (AUTO_SUMMARY=1인 경우)
```

### 6️⃣ 자동 요약 모니터링 (선택)
녹음 중지 후 [📄 보고서 생성] 패널에 진행 상태 표시:

```
패널 상태 표시:
┌─ 주제 ─── [회의록] ──────────────────┐
│  형식 ─── [Word (.docx)]              │
│  [🚀 요약 생성]                       │
│                                       │
│  🔄 서버에서 자동 요약 중...           │
│                                       │
│  LLM 요약 → 문서 생성 → 완료           │
│  ✅        ⏳          ⏳              │
│                                       │
│  📖 보고서 보기    ⬇ 다운로드         │
└──────────────────────────────────────┘

상태 단계:
1. "🔄 서버에서 자동 요약 중..."
2. "🔄 LLM 요약 중 (청크 1/5)..."
3. "🔄 문서 생성 중..."
4. "✅ 완료!" → "📖 보고서 보기" 클릭
```

### 7️⃣ 보고서 조회
```
[📖 보고서 보기] 버튼 클릭 → summary.md 마크다운 표시
또는 [⬇ 다운로드] → .docx/.pdf/.xlsx/.pptx 다운로드
```

## 🔄 프로파일 변경 시나리오

### 시나리오 1: 정확도가 부족한 경우
```
현재: 회의용표준 (8~12초)
문제: "클라우드" → "클라우웃" 오인식 있음

해결:
  1. 드롭다운 → [int8양자화(20~25초)] 선택
  2. 자동 저장됨
  3. 다음 녹음부터 적용 (서버 재시작 불필요)
```

### 시나리오 2: 처리 속도가 너무 느린 경우
```
현재: int8양자화 (20~25초)
문제: 1시간 회의 → 20분 처리 필요

해결:
  1. 드롭다운 → [회의용표준(8~12초)] 또는 [속도우선(5~8초)] 선택
  2. 자동 저장됨
  3. 다음 녹음부터 빠른 처리
```

### 시나리오 3: GPU가 있는 경우
```
현재: 회의용표준 (8~12초)
상황: NVIDIA GPU RTX 3060 사용 가능

해결:
  1. 터미널에서 ctrl+c로 STT 서버 중지
  2. 재시작:
     STT_OPTIMIZATION_PROFILE=gpu-optimized python stt_server.py
  3. 드롭다운에서 [GPU가속(2~4초)] 선택
  4. 약 2~4초로 초고속 처리
```

## ⚙️ 환경변수 설정 (고급)

### 기본값 변경 (환경변수)
```bash
# 모두 기본값: fast-medium (회의용)
python stt_server.py

# baseline (정확도 우선)
STT_OPTIMIZATION_PROFILE=baseline python stt_server.py

# ultra-fast (속도 우선)
STT_OPTIMIZATION_PROFILE=ultra-fast python stt_server.py

# 시나리오 조합
STT_OPTIMIZATION_PROFILE=fast-medium STT_SCENARIO=noisy python stt_server.py
```

### 화자 식별 (선택)
```bash
# 화자 식별 활성 (기본, 각 세그먼트 화자 구분)
python stt_server.py

# 화자 식별 비활성 (모든 세그먼트 "화자1")
ENABLE_SPEAKER_IDENTIFICATION=0 python stt_server.py
# → 추가 20% 속도 향상 (8~12초 → 6~10초)
```

## 💾 저장 옵션 (기본: text)

### 현재 설정 (권장)
```bash
SAVE_MODE=text python stt_server.py
# 저장: txt만 (WAV 불필요)
# 장점: 디스크 절약, 빠른 저장
# 용도: 회의 기록용 텍스트만 필요
```

### 다른 옵션
```bash
# memory: 메모리에만 저장 (서버 재시작 시 초기화)
SAVE_MODE=memory python stt_server.py

# full: WAV + TXT + SRT 모두 저장 (용량 많음)
SAVE_MODE=full python stt_server.py
```

## 🚨 트러블슈팅

### 문제 1: "처리 중이라고만 나오고 진행이 안 됨"
```
증상: [처리중] 상태가 계속 유지
확인:
  1. Python 콘솔 로그 확인
     → "[STT 완료]" 메시지 있는지 확인
  2. 음성이 충분한지 확인 (최소 0.3초)
  3. 마이크 권한 확인
```

### 문제 2: "오류: NVIDIA 없음" (GPU 프로파일 선택 시)
```
해결:
  1. GPU가 없으면 다른 프로파일 선택
  2. 또는 환경변수로 CPU 지정:
     STT_OPTIMIZATION_PROFILE=fast-medium python stt_server.py
```

### 문제 3: "정확도가 떨어짐"
```
원인: 배경음, 시끄러운 환경
해결:
  1. 프로파일을 int8양자화 또는 baseline으로 변경
  2. 시나리오를 noisy로 변경:
     STT_SCENARIO=noisy python stt_server.py
  3. 마이크 위치 조정 (배경음 감소)
```
