## 📌 프로젝트 개요

**프로젝트명:** Q1 신제품 출시 마케팅 캠페인
**기간:** 2026-02-26 ~ 2026-03-19 (3주)
**목표:** 신제품 인지도 40% → 75% 달성
**팀:** Marketing Strategist(기획) / Content Creator(실행) / Campaign Manager(매니저) / Performance Analyst(검사)

---

## 🎯 초기 요청 (사용자)

```
"3주 안에 신제품 출시 마케팅 캠페인을 기획하고 실행해야 합니다.
목표는 B2B 대상 기업 결정권자들의 인지도를 40%에서 75%로 올리는 것입니다.
현재 예산은 $50,000입니다.

AI 팀을 구성해서 다음을 처리해 주세요:
1. 전략 기획 (타겟팅, 채널, 메시지)
2. 콘텐츠 제작 (텍스트, 그래픽, 비디오)
3. 캠페인 실행 및 모니터링
4. 성과 분석 및 최적화"
```

## 👥 Agent 팀 구성

```yaml
Agent #1 - Marketing Strategist (기획가)
├─ 역할: 마케팅 전략 수립
├─ 책임: 시장분석, 타겟팅, 채널전략, KPI 설정
├─ 산출물: 마케팅 계획서

Agent #2 - Content Creator (실행가)
├─ 역할: 실제 콘텐츠 제작
├─ 책임: 카피라이팅, 그래픽 디자인, 비디오 스크립트
├─ 산출물: 콘텐츠 파일들

Agent #3 - Campaign Manager (매니저)
├─ 역할: 캠페인 조율 및 추적
├─ 책임: 일정관리, 상태추적, 의사결정기록
├─ 산출물: 맥락노트, 체크리스트, 상호작용로그

Agent #4 - Performance Analyst (검사관)
├─ 역할: 성과 분석 및 검증
├─ 책임: 콘텐츠 품질검수, KPI 검증, 최적화제안
├─ 산출물: 검수보고서, 성과분석
```
