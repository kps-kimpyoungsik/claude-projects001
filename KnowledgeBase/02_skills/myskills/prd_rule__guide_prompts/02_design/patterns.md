# 설계 단계 - 최적화된 프롬프트 패턴

## 패턴 1: 컴포넌트 설계
```
"<기능명> 컴포넌트 설계를 진행해주세요:

1. 요구사항:
   - 표시할 데이터
   - 사용자 인터랙션
   - 성능 요구사항

2. Props 인터페이스:
   - 필수 Props 정의
   - 선택 Props 정의
   - Props 기본값

3. 상태 관리:
   - 로컬 상태 필요 여부
   - 전역 상태 필요 여부
   - 상태 구조 설계

4. 렌더링 구조:
   - JSX 계층 구조
   - 조건부 렌더링
   - 리스트 렌더링

5. 스타일:
   - CSS 클래스 구조
   - 반응형 디자인 고려

결과를 TypeScript 인터페이스와 함께 제시해주세요."
```

## 패턴 2: 데이터 흐름 설계
```
"'<기능>'의 데이터 흐름을 설계해주세요:

1. 데이터 소스:
   - API 엔드포인트
   - 로컬 상태
   - URL 파라미터

2. 데이터 변환:
   - API 응답 → 컴포넌트 상태로의 변환
   - 입력값 검증 및 정규화

3. 데이터 흐름:
   - 부모 → 자식 (Props)
   - 자식 → 부모 (콜백)
   - 전역 상태 (if needed)

4. 캐싱 전략:
   - 언제 데이터를 다시 로드할 것인가
   - 캐시 무효화 전략

5. 에러 처리:
   - API 오류 처리
   - 입력값 오류 처리
   - UI 피드백

다이어그램으로 흐름을 표현해주세요."
```

## 패턴 3: API 인터페이스 설계
```
"API 인터페이스를 설계해주세요:

1. 요청 정의:
   - HTTP 메서드 (GET/POST/PUT/DELETE)
   - 엔드포인트 경로
   - 쿼리/바디 파라미터
   - 헤더 요구사항

2. 응답 정의:
   - 성공 응답 구조
   - 오류 응답 구조
   - 응답 상태 코드

3. TypeScript 타입:
   - Request 인터페이스
   - Response 인터페이스
   - Error 인터페이스

4. 사용 예시:
   - 호출 코드 샘플
   - 오류 처리 샘플

TypeScript 인터페이스로 명확히 정의해주세요."
```

## 패턴 4: 상태 관리 설계
```
"'<기능>'의 상태 관리를 설계해주세요:

1. 상태 구조:
   - 어떤 데이터를 상태로 관리할 것인가
   - 상태 구조 (객체 형태)
   - 초기값

2. 상태 변경:
   - 어떤 액션이 상태를 변경하는가
   - 각 액션의 영향
   - 액션 실행 조건

3. 선택 기준:
   - 왜 이 상태 관리 방식을 선택했는가
   - 다른 방식과의 비교

4. 구현 방식:
   - useState/useReducer 선택
   - Context/Redux 필요 여부
   - 커스텀 훅 설계

TypeScript로 상태 타입을 정의하고,
상태 변경 흐름도를 제시해주세요."
```

## 패턴 5: 폴더 구조 설계
```
"'<기능>'의 폴더 구조를 설계해주세요:

프로젝트의 아키텍처: <FSD/Clean/etc>

1. 폴더 계층:
   - 각 폴더의 목적
   - 폴더 간 의존성 규칙

2. 파일 조직:
   - 어떤 파일을 어디에 놓을 것인가
   - 파일 명명 규칙

3. 순환 의존성 방지:
   - 의존성 방향
   - 경계 설정

4. 확장성:
   - 새로운 기능 추가 시 폴더 구조

트리 구조로 제시하고, 각 파일의 목적을 명시해주세요."
```

## 패턴 6: 스타일 아키텍처 설계
```
"'<프로젝트>'의 스타일 아키텍처를 설계해주세요:

현재 스택: <CSS Modules/Tailwind/Styled Components/etc>

1. 설계 방식:
   - 글로벌 스타일 vs 컴포넌트 스타일
   - 토큰/변수 시스템
   - 명명 규칙 (BEM/etc)

2. 토큰 정의:
   - 색상 토큰
   - 간격 토큰
   - 폰트 토큰
   - 라디우스/섀도우 토큰

3. 컴포넌트 스타일:
   - 각 컴포넌트의 스타일 구조
   - Props 기반 스타일 변이

4. 테마 지원:
   - 라이트/다크 모드 구현
   - CSS 변수 활용

CSS/SCSS 코드로 예시를 보여주세요."
```
