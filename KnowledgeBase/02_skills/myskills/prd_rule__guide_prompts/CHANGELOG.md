   - 버전 관리
   - 리소스 제한

##### 3. 개발 단계 보안 가이드 (`03_development/security-guide.md`)
**크기**: 1,200줄 | **항목**: 45개

```
✅ 시큐어 코딩 기초
   - 입력값 검증 (Input Validation)
   - SQL 쿼리 안전성 (Parameterized Query)
   - XSS 방지 (Output Encoding)
   - CSRF 방지 (CSRF Tokens)

✅ 인증 & 권한 구현
   - 비밀번호 보안 (bcrypt/argon2)
   - JWT 토큰 관리 (만료시간, Refresh Token)
   - 역할 기반 접근 제어 (RBAC) 구현
   - 리소스 소유권 검증

✅ 데이터 보호
   - 민감정보 제외 (응답/로그)
   - 데이터 암호화 (저장/전송)
   - HTTPS 강제
   - 쿠키 보안 (secure/httpOnly/sameSite)

✅ 보안 헤더 설정
   - X-Content-Type-Options
   - X-Frame-Options
   - Content-Security-Policy (CSP)
   - HSTS
   - X-XSS-Protection

✅ 파일 업로드 보안
   - 파일 타입 검증
   - 파일 확장자 검증
   - 파일 크기 제한
   - 파일명 변경 (보안)
   - 메모리 기반 처리

✅ 로깅 & 모니터링
   - 민감정보 로깅 제외
   - 실패한 로그인 기록
   - 관리자 작업 기록
   - 보안 이벤트 추적
```
