## 산출물

개발 단계에서 생성할 산출물:

1. `<component-name>.tsx` - 컴포넌트 구현
2. `<feature-name>.ts` - 비즈니스 로직
3. `<api-name>.ts` - API 통합 코드
4. `types.ts` - 타입 정의
5. `<hook-name>.ts` - 커스텀 훅
6. `development-notes.md` - 개발 노트
7. `implementation-checklist.md` - 구현 체크리스트
