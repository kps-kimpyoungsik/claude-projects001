# 3. 개발 단계 - 프롬프트 패턴

## 목적
- 코드 구현
- 기능 개발
- 버그 수정
- 성능 최적화
- 코드 리팩토링

## 6단계 개발 프로세스

### Phase 1: 개발 환경 준비
```
개발을 시작하기 전에 다음을 확인해주세요:
- 프로젝트 경로 및 구조
- 설정 파일 검토 (tsconfig, vite.config 등)
- 필수 명명 규칙 및 코드 스타일
- import 경로 및 alias 설정
- 타입 정의 위치
```

### Phase 2: 컴포넌트 구현
```
다음 순서로 컴포넌트를 구현해주세요:
1. Props 인터페이스 정의
2. 컴포넌트 기본 골격 작성
3. JSX 구조 구현
4. 이벤트 핸들러 구현
5. 조건부 렌더링 추가
6. 스타일링 적용
```

### Phase 3: 비즈니스 로직 구현
```
다음을 고려하여 로직을 구현해주세요:
- 데이터 처리 및 변환
- 유효성 검사 및 에러 처리
- 상태 관리 로직
- API 호출 로직
- 조건부 처리
```

### Phase 4: 스타일링
```
다음 기준에 맞춰 스타일을 적용해주세요:
- 프로젝트의 CSS 아키텍처 (CSS Modules/Tailwind/etc)
- 디자인 토큰 및 변수 사용
- 반응형 디자인 구현
- 접근성 고려
- 성능 최적화
```

### Phase 5: 테스트 및 검증
```
구현 후 다음을 검증해주세요:
- 모든 Props 조합이 제대로 작동하는가
- 에러 경우가 잘 처리되는가
- 성능이 acceptable한가
- 접근성을 만족하는가
- 다른 컴포넌트와의 통합이 잘 되는가
```

### Phase 6: 최적화 및 정리
```
최종적으로 다음을 수행해주세요:
- 불필요한 코드 제거
- 성능 최적화 (useMemo, useCallback 등)
- 타입 정확도 검사
- 코멘트 및 문서 추가
- 코드 리뷰 대비
```
