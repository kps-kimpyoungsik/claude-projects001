# 4. 테스트 단계 - 프롬프트 패턴

## 목적
- 단위 테스트 작성
- 통합 테스트 작성
- E2E 테스트 작성
- 성능 테스트
- 접근성 테스트
- 수동 테스트 가이드

## 4단계 테스트 프로세스

### Phase 1: 테스트 계획
```
다음을 포함한 테스트 계획을 수립해주세요:
- 테스트 범위 정의
- 테스트 케이스 목록
- 테스트 시나리오
- 테스트 도구 선택
- 성공 기준 정의
```

### Phase 2: 단위 테스트 작성
```
다음 기준에 맞춰 단위 테스트를 작성해주세요:
- 정상 케이스 (Happy Path)
- 경계값 테스트
- 에러 케이스
- Props 조합 테스트
- 상태 변경 테스트
- 이벤트 핸들러 테스트
```

### Phase 3: 통합 테스트 작성
```
다음 수준의 통합 테스트를 작성해주세요:
- 컴포넌트 간 상호작용
- API 호출 통합
- 상태 관리 통합
- 라우팅 통합
- 폼 제출 통합
```

### Phase 4: 수동 테스트 가이드
```
다음을 포함한 수동 테스트 가이드를 작성해주세요:
- 테스트 환경 설정
- 테스트 단계별 절차
- 예상 결과
- 브라우저 호환성 체크리스트
- 성능 검증 항목
- 접근성 검증 항목
```
