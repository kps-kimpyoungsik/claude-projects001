claude 사용하다고 50%이상 줄일수 있다.
------------------------------------------------------------------------------------
claude 관리자 에서 모든 팀원 settings.json 정의를 고정 할수 있다. 
claude code 메뉴 -> 관리형 설정한다
------------------------------------------------------------------------------------
[https://www.youtube.com/watch?v=gLZ1wJUADqk&list=PLU2dQ9ZkVWp-t9WWGLwx5xbn4BHhDU3XY]
1. 토큰사용량확인
    /context 확인

1. MCP Load 5% 설정한다.
   mcp tool search true
------------------------------------------------------------------------------------
2. 작업단위 
	/rename "로그인"
	/clear 한다.
    /resume 
	#하면 로그인  history를 확인 할 수 있다. 
	/compact "요약내용"
------------------------------------------------------------------------------------

3. 모델 설정 한다.
내가 어떤 플랜을 쓰나

단순 질문(빠름) 
	haiku(주니어)
코딩(위주)
	sonet(중급)

복잡한 설계(꼭필요할때)
	계획 opusplan(시니어)

4. 대화 이어가기 /rename "여기까지 로그인"
   -> /resume 해당 세션으로 이동할수 있다.
5. /compact "요약내용을 넣으면 index 작업내용 index 관리가 된다."
6. /thinking mode default 로 되어 있어 8천 토큰 설정
------------------------------------------------------------------------
7. 오류 hooks 발생시 전처리 에러만 골라서 claude에 전달
------------------------------------------------------------------------------------
